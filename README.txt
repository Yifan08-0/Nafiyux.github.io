更新 GitHub Pages：
1. 登录 GitHub，打开目标仓库，进入 Code → Add file → Upload files。
2. 上传本文件夹内所有 HTML 和 style.css，保持它们在仓库根目录，提交更改。
3. Settings → Pages：Source 选 Deploy from a branch，Branch 选 main，Folder 选 / (root)，保存。
4. 等部署完成，再打开网站，检查首页 Work 1 入口和返回链接。
5. 如页面仍旧，使用 Cmd+Shift+R 或无痕窗口刷新。
