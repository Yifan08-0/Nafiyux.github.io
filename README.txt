银色洞洞板作品集

1. 解压整个文件夹，双击 index.html 查看。
2. 上传到 GitHub 时，将整个文件夹内的文件和 assets 文件夹一起上传，index.html 放在仓库根目录。
3. 首页结构在 index.html；外观在 style.css。
4. board.js 只负责固定钉与孔位对齐；关闭脚本仍可使用页面链接。
5. About Me 内容在 about.html。
6. 保留上传的 work1.html 和 week-1.html、week-2.html、week-3.html 的正文；week-4.html、week-5.html、week-6.html 是新增的反思模板。
7. 没有替你新增反思内容。
