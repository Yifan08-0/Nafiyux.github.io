Creating and hosting a website

A personal learning portfolio built with HTML and CSS, bringing workshop projects and weekly reflections together in one place.

Explore the portfolio ↗

The workshop brief

The workshop introduces three connected practices: managing a site with CampusPress, building pages with HTML and CSS, and publishing files with GitHub Pages. This project develops the coded website part of the brief into a portfolio that can grow throughout the programme.

The website

The homepage introduces Yifan Xu, an MA Digital Media student at the University of Leeds with a background in advertising. It includes an About Me section and a learning archive. This page records the practical website project; the weekly pages are reserved for personal reflections.

  • Home: an introduction and links to the work.
  • About Me: academic background and current coursework.
  • Weekly Reflections: an archive linking to individual pages for Weeks 1–3.
  • Work 1: the project brief, design choices and file structure.

Design and structure

The design uses a learning-board metaphor: paper notes, a yellow introduction tag and a document sleeve for the archive. These elements connect the site to collecting, organising and revisiting ideas. A cream, grey and yellow palette keeps the different pieces visually related.

HTML provides headings, paragraphs, lists and links. The shared external stylesheet controls colour, typography and layout. Separating content from presentation allows the appearance of every page to be updated through one file.

The layout adapts from a sidebar and multi-column board on larger screens to a single column on narrow screens. Ordinary links work without JavaScript. Skip links, visible keyboard focus styles and support for reduced-motion preferences are included.

Hosting and ongoing development

Relative links allow the same files to work locally and under a GitHub Pages repository path. There is no build process or JavaScript dependency. New projects can be added as separate pages and linked from the homepage.
