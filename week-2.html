WEEK 2 / WORKSHOP REFLECTION

Web Scraping

This page is reserved for my weekly reflection.

Using Web Scraper

This week, I used the Web Scraper extension to collect content from the BBC webpage shown in class. By following the teacher’s instructions, I was able to repeat the steps and successfully extract content. This was my first experience of collecting webpage content as data. It also helped me see how the website structures introduced last week could be used in practice.

Difficulties in action

Although the scraping worked, I mainly followed the teacher’s steps without fully understanding what each setting did. If I used a different website, I might not know how to change the settings. This exercise gave me an introduction to web scraping, but I would not say I have mastered the method. There is still a gap between following instructions and using the tool independently.

Website Update

This week, I also developed a new idea for my personal website. I would like to design the homepage as a pegboard, with different sections arranged as items on the board. This could help me organise the sections and give the website a more personal style.
